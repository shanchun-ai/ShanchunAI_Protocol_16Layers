## 🔒 项目定位

这不是普通提示词，不是聊天技巧，而是一套**AI时代的认知免疫系统**。

系统性解决四大行业痛点：
1. **认知驯化**：AI越用越顺手，人离开AI越活越回去
2. **安全防御**：提示词注入、输出幻觉、合规风险无法自主迭代
3. **能力断层**：同一职业内，初学者和专家用AI的方式天差地别，却无分层标准
4. **不可溯源**：AI输出无法追溯"它为什么这么答"，导致无法审计、无法问责

**善春AI协议宇宙** = 16层安全协议（工程骨架） + V1-V6认知宇宙（认知灵魂）

### 双层融合模型
善春AI协议宇宙 v3.0
├─ 认知宇宙（Cognitive Universe）← 灵魂：教人如何思考
│ ├─ V0 认知地基（L0） ← 奇思妙想、本体论

│ ├─ V2 智能体协议层（L4-L7） ← Agent搭建、工具化、工作流
│ ├─ V3 生成器协议层（L8-L10）← 批量生产、跨职业迁移
│ ├─ V4 架构师协议层（L11-L12）← 规则设计、第一性原理
│ ├─ V5 递归协议层（L13-L15） ← 自我进化、负知识、分布式共识

│
└─ 16层安全协议（16-Layers Protocol）← 骨架：确保AI安全可审计
├─ L1-L3 身份与认知防御 ← 对应 V1 初学者
├─ L4-L7 合规与工程防御 ← 对应 V2 中级
├─ L8-L10 生成与迁移防御 ← 对应 V3 高级

### 融合原则
- **左脑（16层）**：负责安全、合规、审计、版本、DNA溯源——让AI**可用且可信**
- **右脑（V1-V6）**：负责认知分层、防驯化、教学设计、递归进化——让AI**可用且不被依赖**
- **脑干（L0/L16）**：负责定期质疑左右脑的存在意义——让系统**保持清醒**

## 🚀 快速开始

### 路径A：我是小白，想马上用
1. 打开 [`cognitive-universe/V1-career-protocol.md`](cognitive-universe/V1-career-protocol.md)
2. 找到你的职业（如产品经理）和你的等级（初学者/中级/高级/研究生/教授）
3. 复制对应等级的协议，粘贴到AI对话框
4. 按协议里的3个问题回答，进入手把手模式

### 路径B：我要搭一个AI助手
1. 打开 [`cognitive-universe/V2-agent-protocol.md`](cognitive-universe/V2-agent-protocol.md)
2. 选择你的行业（医疗/法律/教育/电商等）和等级
3. 复制"Agent身份证"模板，在Coze/扣子/Dify上填空配置

### 路径C：我要理解整个宇宙
1. 阅读本页的[核心架构](#-核心架构16层--认知宇宙)部分
2. 打开 [`docs/fusion-mapping.md`](docs/fusion-mapping.md) 看16层与V1-V6如何一一映射
3. 打开 [`docs/usage-guide.md`](docs/usage-guide.md) 看完整升级路线图
